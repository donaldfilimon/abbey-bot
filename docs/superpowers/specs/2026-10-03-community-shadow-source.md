## Decisions this draft pins or leaves for root review

- Recommended compatible choice: default-off owner shadow scope and independent operational file, preserving existing policy version 1 and legacy JSON defaults. Add the field to existing Policy fixtures. This is an additive local schema, not an ABI dependency or a new database/dependency.
- Recommended bound: 1,000 retained cases; fail closed when full. No pruning/retention interval is invented. A reviewed archival/retention policy is needed before a long-running pilot reaches that bound. Learning erasure does not silently delete operational evidence, and the UI must state this distinction.
- Recommended first producer: actual human-assessed `/modcall`, including ambiguity and quotation referrals. This does not implement an independent model recommendation/classification stream. The ledger labels its origin, and the source receipt must keep that remaining proof gap explicit. Adding local model classification later needs its own bounded schema and native evidence qualification.
- Recommended conservative appeal scope: same guild and original source channel, current member == subject, no cross-guild or DM transfer. Future sanctions may restrict this route, so eventual enforcement activation cannot reuse it without separately validating a usable appeal route for timed-out/removed members.
- Recommended review independence: original assessor cannot review; original reviewer cannot resolve an appeal. A lone moderator cannot produce independent qualification evidence. No threshold or activation is chosen by this draft.
- Staff/appeal Discord notifications, live tests, owner policy edits, migration, activation, installed runtime and human pilot are out of this source task. Classic private command responses are the implementation surface; this researcher performs none.

## Native addendum — 2026-10-03

Current production `/modcall source_message` is already `Option<String>` and its registration is a decimal string. Protected private review is deliberately available while protected source capture is refused. Stop and disabled capture preserve existing authorized show/review/appeal/resolution; they refuse a new edited source version. Source proof begins at the earliest native GET so response latency cannot mint a newer permission lease. The original source version must match for confident review/resolution; current missing/changed proof can create only explicit NeedsContext.

These aggregate numbers measure saved human assessments, independent human reviews and subject appeal states; they do not measure independent classifier precision or authorize activation.

Native registered dispatch fixtures seed cases only through root's actual `/modcall` producer, then exercise all four leaves. The source draft has no provider, enforcement, public notice, unsolicited DM or policy mutation path. Human appeal utility after losing guild membership/source access remains an explicit gap requiring a separately reviewed route.
